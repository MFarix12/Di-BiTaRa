# Latar zon HD

Built-in image_gen, edit berasingan untuk tiga aset asal dalam public/images/zones. Output sebenar 1672 × 941 PNG; sumber asal 1280 × 720 JPEG. Permintaan prompt 3840 × 2160 tidak dipenuhi oleh output alat; tiada dakwaan output 4K. Sedikit butiran kecil berubah dalam penjanaan semula, pemandangan dan susun atur utama kekal. Imej asal dikekalkan.

Aset aktif:
- public/images/zones/zone-2-airport-hd.png
- public/images/zones/zone-3-flight-deck-hd.png
- public/images/zones/zone-4-cabin-hd.png

config/zone-backgrounds.php ditukar kepada aset HD. Komponen latar, preload, kad zon dan thumbnail berkongsi konfigurasi ini. Kedudukan/cover dan gaya UI kekal. Ketiga-tiga URL aset berjaya HTTP 200.

## Prompt akhir bagi setiap edit

Edit target: supplied existing Di-BITaRa zone background. This is a faithful high-resolution restoration only, NOT a redesign. Recreate this exact image at 3840 x 2160 (16:9), improving crisp edge fidelity, clean fine illustration detail, smooth gradients, and removing JPEG blur/artifacts. Preserve the exact camera position, framing, perspective, composition, spatial layout, all objects and their positions and proportions, original blue/navy/yellow/white colors, lighting, cheerful mood and original illustrated rendering style. Every plane, chair, window, screen, tower, cloud, sign, runway and decoration must stay where it is. Do not add or remove objects, do not change scene or lighting or colors, do not add text, people, logos or UI. Preserve the calm background quality for readable interface overlays. Output one single full-bleed enhanced version, no comparison panels.
