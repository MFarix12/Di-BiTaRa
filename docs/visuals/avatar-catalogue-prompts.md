## Prompt bersama (digabung dengan subjek di bawah)

Use case: illustration-story. Create ONE production-ready character avatar for the Malaysian primary-school Di-BiTaRa learning app. The attached pilot mascot is a STYLE REFERENCE ONLY; do not copy its identity, outfit or pose. Match the same polished cheerful chibi illustration language: large expressive dark eyes, large rounded head, small body, clean dark navy outlines, rich softly shaded colours, tidy glossy highlights, cute childlike adventure crew, navy/blue, gold and white unifying accents. Subject: [SUBJEK]. Portrait orientation 2:3, single FULL BODY character completely visible from hair/hat/helmet to feet, centred, character occupies 85% height with generous empty transparent padding around all sides. Individual identifiable role, distinct face, hair, outfit and accessories as specified. Keep accessories close to the body so this reads clearly at small avatar size. Genuine transparent background. No scene, no ground shadow, no text, no lettering, no watermark, no logos, no border, no duplicate people. Friendly age-appropriate aspirational costume, nonsexualized.
